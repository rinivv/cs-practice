Рабочая папка - место для хранения и работы над файлами
Индекс - промежуточный результат перед сохранением изменений
Коммит - комада, сохраняющая промежуточный результат
Различие Git и GitHub - первое управляет версиями, второе предоставляет размещение репозиториев и средства совместной работы
Git diff - разница между рабочей директорией и индексом
Git diff --staged - разница между индексом и последним коммитом
Git status - показывает состояние репозитория (готово ли к индексу, например)
Ветка - независимая последовательность коммитов в истории разработки, при коммите ее показатель перемещается на новый коммит. Слияние переносит изменения из одной ветки в другую.
