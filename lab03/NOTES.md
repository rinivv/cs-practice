git diff - показывает разницу между двумя версиями
git show - показывает содержимое конкретного коммита
git log - показывает историю коммитов
log -S - показал коммиты с деталями изменений для каждого коммита
git blame - показал, какая строка кем и в каком коммите была изменена
git restore - отменяет локальные изменения и возвращает файл к последнему коммиту
git restore --source - позволяет взять версию файла из конкретного коммита
Мы бы просто откатили файл к последнему коммиту
git revert - не удаляет коммит а создает новый, который отменяет предыдущий
git reset --hard - полностью удаляет коммит из истории
1 безопаснее 2 так как оно не переписывает историю, а продолжает, в то время как 2 может сломать всё опубликованное
В отличие от ветки, тег не двигается и остается привязанным к одному коммиту
